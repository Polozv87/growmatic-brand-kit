# Growmatic — Paquete de marca v1.0

Abril 2026

## Contenido

- /logo           — Logo completo (imagotipo) · 4 variantes
- /symbol         — Solo símbolo (isotipo) · 4 variantes
- /wordmark       — Solo wordmark · 2 variantes
- /app-icon       — App icons para iOS/Android/store · PNG 256/512/1024
- /favicon        — Favicons para navegador · PNG 16/32/48/64/128/256
- Growmatic-Manual-de-marca.html — Manual completo (abre e imprime a PDF)

## Uso rápido

- Web / app (fondo oscuro): growmatic-logo-dark.svg
- Print / papelería fondo claro: growmatic-logo-light.svg
- Una sola tinta: growmatic-logo-mono-white.svg o mono-black.svg
- Favicon: favicon/favicon-32x32.png
- App icon iOS: app-icon/app-icon-green-1024.png (verde) o dark-1024.png
